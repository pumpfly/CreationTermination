An entity with a BackgroundComponent is like the name implies the Background of the games scene. Background entities have the possibility to scroll. To make the scrolling seamless a copy of the backgrounds sprite will be rendered which ideally will be positioned at the end of the original sprite even though the user can freely choose what value
