std::function<void()> gl3::brewEngine::collision::ColliderComponent::handleCollision

handleCollision() is a lambda function that is a parameter of the ColliderComponent constructor. If the user adds a ColliderComponent to an entity, handleCollision's definition is the input. This function will only get called on collision.
